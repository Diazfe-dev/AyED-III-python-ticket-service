# MEMORY.md

Memoria persistente del proyecto, en modelo híbrido (ver la regla en [AGENTS.md](AGENTS.md)). Se lee entero al empezar cada sesión (es chico) y se actualiza al terminar cada tarea.

- **Decisiones y errores a evitar viven en Engram**, proyecto `tp-final`, un registro atómico por ítem (qué, por qué, dónde). Topic keys: `tp-final/decision/<slug>` y `tp-final/pitfall/<slug>`.
- Cómo consultarlos: `mem_search` por tema (p. ej. "worktree", "404 ticket ajeno"), después `mem_get_observation` con el id para ver el contenido completo. Sin las herramientas MCP: `engram search "<tema>" --project tp-final`.
- La versión anterior de este archivo (con todas las decisiones y errores en texto) queda en el historial de git (`git log -- MEMORY.md`).
- En "Cambios y motivación", `D:` = `tp-final/decision/` y `P:` = `tp-final/pitfall/`.
